## Overview

OBS LocalVocal is an OBS Studio plugin that performs real-time speech-to-text transcription entirely on-device using OpenAI's Whisper model via whisper.cpp, generating live captions as an OBS text source without sending any audio to external cloud services. With optional CUDA and Metal GPU acceleration and support for over 90 languages, it brings professional-grade captioning to every streamer at zero ongoing cost.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **OBS LocalVocal** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Local Whisper AI** | On-device whisper.cpp inference — no cloud API, no cost, no privacy risk |
| **Live OBS Captions** | Transcribed text appears as a configurable OBS text source in real time |
| **90+ Languages** | Supports over 90 languages with automatic spoken language detection |
| **GPU Acceleration** | CUDA and Metal GPU acceleration for low-latency transcription |
